# 测试方案

```bash
pixi run test
```

测试不访问外网。接口测试在进程内调用同一套引擎。

| 需求 | 测试 | 期望 |
| --- | --- | --- |
| 断线补数且不重复更新价格 | `test_gap_replay_does_not_update_the_price_again` | 6 个时间戳只更新 6 次；主源序号 1–6 补齐 |
| 旧数据不能把价格打回去 | `test_stale_replay_does_not_move_the_market_backward` | 回补更早的行情后最新价不变 |
| 未到 3% 不熔断 | `test_loss_short_of_three_percent_does_not_halt` | 亏损 29900 时未熔断 |
| 达到 3% 后禁开仓、可平仓 | `test_three_percent_loss_halts_open_and_still_allows_close` | 亏损 30000，开仓拒绝，平仓成交 |
| 重复行情不重复报警 | `test_same_tick_from_backup_does_not_emit_a_second_halt` | 熔断事件只有一条 |
| 熔断不自动恢复 | `test_halt_stays_until_resume` | 价格回到成本后仍拒绝开仓；人工恢复后可以开仓 |
| 2% 告警去重与恢复 | `test_daily_loss_alert_fires_once_and_recovers` | 告警只发一次，回落后发恢复事件 |
| 回撤限制拒开仓 | `test_drawdown_restrict_blocks_open` | 回撤 5% 时拒绝开仓 |
| 集中度限制拒加仓 | `test_concentration_restrict_blocks_add_on_top_instrument` | 最大敞口品种被拒，小品种可加 |
| 多账户独立，Gamma 亏到 3% 熔断 | `test_accounts_stay_separate_and_gamma_halts_at_three_percent` | 螺纹昨结算 3080、价格 2930，只熔断 Gamma，盯市 -30000 |
| 公开行情解析 | `test_sina_parser_reads_commodity_and_index_quotes` | 商品和股指的最新价、交易所时间读对；测试本身不访问外网 |
| 单品种敞口 | `test_notional_cap_blocks_another_open` | 名义本金超限时拒绝加仓 |
| 按账户、按合约查询 | `test_positions_can_be_queried_by_account_and_instrument` | 螺纹同时看到 Alpha 和 Gamma |
| 可平量 | `test_close_rejects_more_than_the_open_position` | 超过持仓的平仓被拒 |
| 样例配置里的交易所 | `test_config_covers_three_exchanges` | 配置里有上期所、大商所、中金所，熔断比例 0.03 |
| 逐日盯市 | `test_mark_to_market_settles_yesterday_and_today_lots` | 两日权益 1,004,980.00 和 1,008,772.00 |
| 空头盯市 | `test_short_position_profits_when_settlement_falls` | 结算价下跌时空头盈利 2000 |
| 先开先平 | `test_close_uses_fifo_and_the_older_basis` | 平仓先吃掉昨仓 |
| 监控接口 | `test_order_position_and_snapshot_round_trip` | 下单、持仓查询、快照和首页可用 |
| 回测验证规则 | `test_backtest_replays_gamma_alert_then_halt` | 告警→熔断→开仓拒绝，盯市 -30000 |
