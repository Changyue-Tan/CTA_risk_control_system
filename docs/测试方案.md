# 测试方案

运行：

```bash
pixi run test
```

测试不访问外网，也不依赖监控台进程。接口测试用 FastAPI 的 TestClient 在进程内打到同一套引擎。

| 需求 | 测试 | 期望 |
| --- | --- | --- |
| 两个行情源，断线后补数且不重复触发 | `test_gap_replay_fills_tape_without_extra_price_updates` | 6 个时间戳只更新 6 次价格；主源序号 1–6 补齐；回补不再增加更新次数 |
| 旧数据不能把价格打回去 | `test_stale_replay_does_not_move_the_market_backward` | 回补更早的 tick 后最新价不变 |
| 主源优先 | `test_primary_overrides_backup_disagreement_once` | 同一时间戳价格不一致时采用主源，备份源不能再覆盖 |
| 运行中的双源丢包 | `test_live_feed_outage_replays_a_contiguous_tape` | 11 拍后缺口全部闭合，主源序号连续 |
| 单日浮亏未到 3% 不熔断 | `test_loss_short_of_three_percent_does_not_halt` | 亏损 29900 时账户未熔断 |
| 达到初始资金 3% 熔断，禁开仓、可平仓 | `test_three_percent_loss_halts_open_and_still_allows_close` | 亏损 30000，开仓拒绝，平仓成交 |
| 配置文件中的 Gamma 验收账户 | `test_yaml_acceptance_shock_matches_the_three_percent_case` | 价格 3300，盯市 -30000.00，开仓被拒，平仓通过 |
| 重复行情不重复报警 | `test_same_tick_from_backup_does_not_emit_a_second_halt` | 熔断事件只有一条 |
| 熔断不自动恢复 | `test_halt_stays_until_resume_and_resume_rechecks_the_loss` | 价格回到成本后仍拒绝开仓；人工恢复后可以开仓；亏损未消除时恢复无效 |
| 多账户独立 | `test_accounts_are_isolated_when_the_same_price_moves` | 同一笔螺纹行情只熔断 Gamma，不熔断 Alpha、Beta |
| 回撤限制开仓 | `test_drawdown_restricts_new_opens` | 回撤 10% 时开仓被拒 |
| 单品种保证金上限 | `test_single_instrument_margin_cap_blocks_the_add` | 超限加仓被拒 |
| 集中度 | `test_concentration_blocks_only_when_two_products_are_open` | 两个品种且单一占比达到 80% 时拒绝继续加仓 |
| 按账户、按合约查询 | `test_positions_can_be_queried_by_account_and_instrument` | 螺纹同时看到 Alpha 和 Gamma；Beta 只有股指 |
| 可平量 | `test_close_rejects_more_than_the_open_position` | 超过持仓的平仓被拒 |
| 逐日盯市、保证金 | `test_mark_to_market_settles_yesterday_and_today_lots` | 两日权益分别为 1,004,980.00 和 1,008,772.00，并写出日报 |
| 空头盯市 | `test_short_position_profits_when_settlement_falls` | 结算价下跌时空头盈利 2000 |
| 先开先平 | `test_close_uses_fifo_and_the_older_basis` | 平仓先吃掉昨仓，盈亏按昨结算价计算 |
| 回测复用同一套规则 | `test_builtin_replay_rejects_the_open_after_the_loss_limit` | 回放结束后账户熔断，开仓被拒 |
| 配置覆盖三家交易所 | `test_config_file_has_the_three_exchanges_and_accounts` | SHFE、DCE、CFFEX，三个账户，熔断比例 0.03 |
| 监控接口 | `test_order_position_and_snapshot_round_trip` | 下单、持仓查询、快照和首页可用 |

手工看监控台时，先 `pixi run serve`，再点“熔断验收”。Gamma 应变为熔断，开仓失败，平仓成功。点“缺口回补演示”应看到回补前后价格更新次数相同。点“按最新价清算”应打开当日 HTML 日报。
