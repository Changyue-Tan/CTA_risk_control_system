# 多品种期货交易风控与清算

上海宽投资产管理有限公司机试题的一个可运行实现。系统覆盖双源行情、多账户持仓、盘中风控（含 3% 熔断）和逐日盯市日报。不连接真实交易所。

## 环境

依赖由 pixi 管理，虚拟环境在 `.pixi/envs/default`。

```bash
pixi install
pixi shell          # 进入环境
pixi run test       # 单元测试
pixi run demo       # 打印验收场景
pixi run serve      # 打开监控台 http://127.0.0.1:8000
```

也可以直接执行 `bin/cta-risk`，效果与 `pixi run serve` 相同。

## 监控台

页面每秒刷新账户对比、行情、品种敞口、持仓和风控事件。

- 提交委托：开仓和平仓都会先过风控。熔断账户只能平仓。
- 熔断验收：把 Gamma 的螺纹价格打到初始资金 3% 的当日亏损，开仓被拒绝，平仓可以成交。
- 按最新价清算：用当前最新价做结算价，生成 `reports/risk_report_YYYYMMDD.html`。
- 解除熔断：人工恢复。如果亏损仍在阈值上，恢复会立刻再次熔断。
- 缺口回补演示：不改动实盘簿记，单独跑一遍主源丢号、备份源顶上、主源回补。
- 回测样例：用固定历史行情回放同一套规则。

三个样例账户在 `config/system.yaml`：

| 账户 | 初始资金 | 昨仓 |
| --- | --- | --- |
| alpha 趋势 | 1000 万 | 螺纹多 30，铁矿空 15 |
| beta 套利 | 500 万 | 沪深 300 多 5，中证 500 空 4 |
| gamma 验收 | 100 万 | 螺纹多 20，基准价 3450 |

Gamma 的熔断价是 3300。`(3300 - 3450) × 20 × 10 = -30000`，正好是 100 万的 3%。

## 目录

```
config/system.yaml          品种、账户、阈值、模拟行情
src/cta_risk/               行情、持仓、风控、清算、回测、接口
src/cta_risk/static/        监控台页面
tests/                      与验收场景对应的测试
scripts/demo_acceptance.py  命令行验收输出
docs/                       设计说明和测试方案
```

设计取舍和清算公式见 `docs/设计说明.md`。测试和需求的对应关系见 `docs/测试方案.md`。
