# 多品种期货交易风控与清算

上海宽投资产管理有限公司机试题的一个可运行实现。最新价从新浪财经和东方财富的公开行情拉取，不连接柜台。昨结算写在配置里。

## 运行

依赖由 pixi 管理，环境在 `.pixi/envs/default`。

```bash
pixi install
pixi run test
pixi run demo
pixi run serve      # 监控台 http://127.0.0.1:8000
```

也可以执行 `bin/cta-risk`，效果与 `pixi run serve` 相同。

## 监控台能做什么

页面打开时价格停在 `config/system.yaml` 里的昨结算价。

- 拉取真实行情：向新浪和东财各要一次最新价。同一笔交易所时间只更新一次。
- 提交委托：先检查熔断、单品种敞口和可用资金，通过后按委托价成交。
- 熔断验收：Gamma 持有螺纹多 20 手、乘数 10。价格比昨结算 3080 低 150 点，打到 2930，亏损正好 3 万，也就是初始资金 100 万的 3%。开仓被拒绝，平仓可以成交。
- 按最新价清算：用当前最新价做结算价，写出 `reports/risk_report_YYYYMMDD.txt`。
- 解除熔断：人工恢复。亏损还在阈值上时会马上再次熔断。

| 账户 | 初始资金 | 昨仓 |
| --- | --- | --- |
| alpha | 1000 万 | rb2701 多 30，i2701 空 15 |
| beta | 500 万 | IF2612 多 5，IC2612 空 4 |
| gamma | 100 万 | rb2701 多 20，昨结算 3080 |
